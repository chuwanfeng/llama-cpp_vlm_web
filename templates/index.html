❓ 使用帮助

🚀 快速开始

  1. 选择后端 — 在侧边栏选择 llama-cpp（本地）或厂商 API（OpenAI/DeepSeek 等）
  2. 选择模型 — 选择要使用的具体模型
  3. 开始对话 — 输入消息，按 Enter 发送
  4. 使用工具 — 在设置中启用工具调用，Agent 会自动使用工具

💡 高级功能

  • Plan 模式 — 点击 📋 按钮，Agent 会先制定计划再执行
  • 联网搜索 — 点击 🌐 按钮，Agent 可搜索互联网信息
  • 文件上传 — 点击 📎 按钮上传图片或文本文件
  • 模板 — 保存常用提示词，快速调用
  • 技能 — 创建自定义技能，扩展 Agent 能力

🔧 工具调用

启用工具后，Agent 可以：

  • 读取和编辑文件
  • 执行终端命令（需审批）
  • 搜索网络信息
  • 浏览网页
  • 管理进程

⚠️ 危险操作需要审批，可在设置中查看审批队列。

⚙️ 设置说明

  • Temperature — 创造性 vs 确定性（0=保守，2=随机）
  • Max Tokens — 单次回复最大长度
  • 辅助模型 — 用于压缩/记忆等杂活，节省主模型 token
  • YOLO 模式 — 跳过所有审批（谨慎使用）

⌨️ 快捷键

  • Enter — 发送消息
  • Shift + Enter — 换行
  • Ctrl + / — 聚焦输入框
  • Esc — 停止生成
