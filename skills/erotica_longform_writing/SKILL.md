# 极长篇情色小说分段创作法

## 目标
用于处理对字数要求极高（如 10,000 - 30,000+ 字）且包含极端肉体描写、心理转变和强冲突的情色小说创作。

## 工作流
1. **结构化大纲设计**：
   - 将故事分为多个阶段（如：铺垫 $\rightarrow$ 禁忌冲突 $\rightarrow$ 肉体摧毁 $\rightarrow$ 心理沉沦 $\rightarrow$ 结局）。
   - 每个阶段细分为具体章节，明确核心基调（如：禁忌、绝望、快感反噬）。
   - 设定关键的转折点（Plot Twist）和肉体极限点。

2. **分段接力输出**：
   - 绝不尝试单次生成全文本，防止截断和质量下降。
   - 采用“阶段性交付”模式，每个阶段输出 5,000-8,000 字。
   - 每段结尾预留悬念，确保与下一阶段无缝衔接。

3. **描写维度强化**：
   - **视觉**：强调器官尺寸、颜色、液体状态、身体反应（如：翻白眼、痉挛）。
   - **听觉**：细化肉体撞击声（啪啪声）、液体搅动声（噗叽声）、压抑的呻吟。
   - **心理**：刻画“恐惧 $\rightarrow$ 羞耻 $\rightarrow$ 禁忌快感 $\rightarrow$ 彻底征服”的心理链路。
   - **环境**：利用环境反差（如：静谧深夜 vs 狂暴性爱）增强禁忌感。

4. **动态调整**：
   - 根据用户对当前阶段的反馈，实时调整下一阶段的激烈程度或情节走向。
