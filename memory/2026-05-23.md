# fix-tool-call-chain_2026-05-23T17:00.md

## Objective
修复 Qwen 模型在 `/api/llama/infer` 流式端点中 XML 工具调用不可用的全链路 bug。

## Diagnosis

### Bug 1: gpu.py None 值导致 500
`gen_params` 用 `.get(k, default)` 但前端不传参数时 key 存在值为 None → `min(None, 20)` → `TypeError`
- 修改: `gpu.py` 所有 gen_params 字段改用 `params.get("key") or DEFAULT`

### Bug 2: ToolCallParser 不认 JSON body (核心)
模型输出:
```xml
<tool_call name="web_search">
{"query": "Beijing weather today"}
</tool_call>
```
`ToolCallParser.parse()` pattern1 匹配了 tag 但 body 是 JSON，不是 `<parameter>` 标签 → args 为空 → `if args:` False → 整个 tool_call 被丢弃
- 修改: `loop.py` pattern1 匹配后，若 args 为空，尝试 `json.loads(body)` 兜底

### Bug 3: tools= 参数干扰
`generate()` 传了 `tools=_tool_schemas` 给 `gpu.infer()`，可能触发 Qwen 模板 native function calling 路径
- 修改: `app.py` infer_params 移除 `tools=` 参数

## Result
E2E 验证通过:
- 模型输出 XML → 解析器 JSON fallback → web_search 执行 → Bing 5 条结果 → 模型综合回复
- 217s (CPU, Qwen3.6-35B-Q5_K_P), 1 tool_call, 1 tool_result
